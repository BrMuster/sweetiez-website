Plot a CSV

Your file stays in your browser and is never uploaded. Hover the graph to read exact values. Pick one of the six Range buttons, then drag across the graph to mark that range and see its min, max and average. Click inside a highlighted band to zoom in. You can also type exact From / To values for any range.

The first row is treated as column names if it contains any text. Each Range button holds its own selection, so you can compare up to six. With no range marked, the table covers everything currently shown. Units are labels only; they don't convert the numbers. Overlays use their own first column as X; "Export range as CSV" saves the main scan only.
